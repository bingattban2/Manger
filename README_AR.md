# إدارة التمام اليومي — manger 2.0.4

مشروع Android (Kotlin / Jetpack Compose) للأفراد والمواقع والتحضير والكشوف والتقارير.

## تحديث هذه النسخة

- تحسين «أسماء القوة»: انكماش تدريجي للأدوات عند السحب للأعلى، ورأس جدول ثابت أثناء التمرير العمودي، وعمود الاسم ثابت على يمين الشاشة أثناء التمرير الأفقي بينما يتحرك رأس الاسم وصفوف الافراد عمودياً مع الجدول.
- عرض خلايا أيام الشهر ضمن نافذة مرئية مع المحافظة على عرض الشهر الكامل؛ لتقليل تكلفة رسم العناصر خارج الشاشة.
- إزالة زر إضافة البيانات التجريبية، وأسماء وكلمات مرور الحسابات التجريبية من شاشات تسجيل الدخول.
- عدم إنشاء حسابات تجريبية عند تثبيت جديد، وإزالة بيانات الاعتماد التجريبية القديمة فقط إذا كانت كلمات المرور ما زالت افتراضية، مع حماية الحسابات المخصصة وبيانات الافراد.
- بعد مرور عشر دقائق في الخلفية، تظهر شاشة الدخول داخل النشاط نفسه مع الاحتفاظ بشاشة العمل أسفل قفل كامل الشاشة وعدم إنهاء التطبيق.
- جدولة المزامنة كل ساعة عبر WorkManager بعد تفعيل اتصال السيرفر الموثوق، والحفاظ على عمليات المزامنة المعلقة حتى تأكيد الاستلام.
- تنظيف التعليقات غير الضرورية، وإبقاء تعليقات مواضع الربط `SERVER:`.

## الربط بالسيرفر

**لا يوجد اتصال إنتاجي مفعل الآن.** لا تُنشأ حسابات إدارة أو مشرفين افتراضية للتثبيت الجديد. يتطلب استخدام حساب حقيقي ربط Supabase Auth وإعداد جداول RLS، وتوفير حساب إدارة فعلي قبل أول دخول. راجع `SERVER_CONNECTION_POINTS_AR.md`.

لن يُمسح كشف أفراد أو سجلات تحضير قائمة أثناء ترقية التطبيق. يجب الاحتفاظ بنسخة احتياطية من البيانات قبل تطبيق التحديث.

## البناء

افتح المشروع بالكامل في Code on the Go، مع الاحتفاظ بملفات Tajawal والموارد المرفقة، ثم شغّل:

```
:app:clean :app:assembleDebug
```

تأكيد نجاح البناء والتمرير على Android يتطلب اختباره على هاتف حقيقي. لم يتم تنفيذ `assembleDebug` في بيئة إعداد هذه النسخة.
